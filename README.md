# The Lost Secret: Fenrir's Legacy
The Lost Secret II: Fenrir's Legacy is a custom game built using Tomb Raider Next Generation (TRNG) engine.<br>
This repository serves the codebase used to compile game's executable files, along with in-game SCRIPT for internal gameplay management and events.

## Chapter 1
Only the 1st chapter of the game is developed at the present time. If I decide to develop it further, I will include the new files in this repository as soon as they're baked and ready.

## TRNG
Tomb Raider Next Generation Engine (TRNG) is a custom engine made by Paolone, built on top of old-school Tomb4 engine, which was used for making Tomb Raider 4 - The Last Revelation and its predecessors.<br>
Many features were brought back to life, as well as the ability to customize almost all the existant mechanics inside the game.
